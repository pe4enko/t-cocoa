# Telegram-бот для расчета спреда какао

Бот считает, насколько российский фьючерс на какао отклонился от зарубежного рынка после закрытия внешней сессии.

Источники данных сейчас такие:

- локальное какао: напрямую с `MOEX ISS`, автоматический выбор ближайшего неистекшего контракта по `RU_COCOA_ASSET_CODE=COCOA`
- курс доллара: `USDRUBF` из TradingView
- зарубежное какао на закрытии: `COCOA` из TradingView
- время открытия внешнего рынка: `FOREIGN_OPEN_TIME_MSK=11:45`
- время закрытия внешнего рынка: `FOREIGN_CLOSE_TIME_MSK=20:29`
- праздники внешнего рынка: `FOREIGN_MARKET_HOLIDAYS_MSK=2026-01-01,2026-01-19,2026-02-16,2026-04-03,2026-05-25,2026-06-19,2026-07-03,2026-09-07,2026-11-26,2026-12-25`
- расчетный базис: рассчитывается автоматически по ставке и времени до экспирации
- ставка для базиса: либо автоматически с сайта ЦБ РФ, либо вручную через `FAIR_BASIS_RATE_PCT`

## Что считает бот

Формулы теперь построены вокруг базиса, а не ручной долларовой поправки:

- `Локальный контракт в долларах = Текущая цена локального контракта * 1000 / Курс доллара`
- `Текущий базис = Локальный контракт в долларах - Цена закрытия зарубежного какао`
- `Расчетный базис = Цена закрытия зарубежного какао * Ставка * Дни до экспирации / База_дней`
- `Справедливая цена локального контракта в долларах = Цена закрытия зарубежного какао + Расчетный базис`
- `Справедливая цена локального контракта в рублях = Курс доллара * Справедливая цена локального контракта в долларах / 1000`
- `Отклонение текущего базиса от расчетного = Текущий базис - Расчетный базис`

Дополнительно бот показывает:

- короткий итоговый блок: справедливая цена в ₽ и $, спред к справедливой цене и рекомендация `лонг/шорт`
- раскрывающийся блок с деталями расчета, текущим и расчетным базисом, источниками и временем котировок
- если команда пришла во время торгов внешнего рынка, бот не считает спред и сообщает, что расчет будет доступен после закрытия

## Команды

- `/start` или `/help` — показать справку
- `/cocoa` — расчет с автоматически выбранным актуальным контрактом
- `/cocoa CCJ6` — разовый расчет с конкретным MOEX-кодом локального фьючерса
- `/calc` — алиас команды `/cocoa`

## Настройка

1. Скопируйте `.env.example` в `.env`.
2. Заполните `BOT_TOKEN`.
3. При необходимости поправьте `RU_COCOA_ASSET_CODE`, `TV_USDRUBF_SYMBOL`, `TV_WORLD_COCOA_SYMBOL`, `FOREIGN_OPEN_TIME_MSK`, `FOREIGN_CLOSE_TIME_MSK` и `FOREIGN_MARKET_HOLIDAYS_MSK`.
4. Настройте расчетный базис через `FAIR_BASIS_DAY_COUNT`.
5. Оставьте `FAIR_BASIS_RATE_PCT=` пустым, чтобы ставка бралась автоматически с ЦБ РФ, или задайте число вручную как override.
6. При необходимости поменяйте `CBR_KEY_RATE_URL`, если захотите использовать другой официальный адрес страницы ЦБ.
7. При необходимости отключите кеши через `CBR_KEY_RATE_CACHE_ENABLED=false` и `TV_WORLD_CLOSE_CACHE_ENABLED=false`.
8. При необходимости настройте пороги сигнала через `SIGNAL_*`.
9. Установите зависимости и запустите бота.

```bash
pnpm install
pnpm dev
```

Для продакшена:

```bash
pnpm build
pnpm start
```

## Docker Compose

Можно запускать бота через Docker Compose без публикации образа в реестр.

В текущей конфигурации из [compose.yaml](/Users/ma.martynov/work/t-cocoa/compose.yaml):

- образ собирается локально на сервере из [Dockerfile](/Users/ma.martynov/work/t-cocoa/Dockerfile)
- образ получает локальный тег `t-cocoa-bot:local`
- образ не публикуется в Docker Hub, GHCR или другой registry автоматически
- `.env` подставляется в контейнер с сервера и не запекается в образ

Команды на VPS:

```bash
docker compose build
docker compose up -d
docker compose logs -f
```

Обновление после изменений:

```bash
git pull
docker compose up -d --build
```

## GHCR и VPS без исходников

Проект также подготовлен к публикации образа в GitHub Container Registry через GitHub Actions:

- workflow: [.github/workflows/publish-ghcr.yml](/Users/ma.martynov/work/t-cocoa/.github/workflows/publish-ghcr.yml)
- deploy compose: [compose.ghcr.yaml](/Users/ma.martynov/work/t-cocoa/compose.ghcr.yaml)
- целевой образ: `ghcr.io/pe4enko/t-cocoa:latest`

Что происходит:

- при push в `main` GitHub Actions собирает Docker-образ
- образ публикуется в `ghcr.io/pe4enko/t-cocoa`
- на VPS не нужны `node`, `pnpm` и исходники проекта

Что нужно на VPS:

1. Установить только Docker и `docker compose`.
2. Положить на сервер два файла:
   - `.env`
   - `compose.ghcr.yaml`
3. Войти в GHCR:

```bash
echo <GITHUB_PAT> | docker login ghcr.io -u pe4enko --password-stdin
```

4. Запустить контейнер:

```bash
docker compose -f compose.ghcr.yaml pull
docker compose -f compose.ghcr.yaml up -d
```

Обновление на VPS:

```bash
docker compose -f compose.ghcr.yaml pull
docker compose -f compose.ghcr.yaml up -d
```

Если пакет в GHCR будет приватным, для входа на VPS нужен GitHub token с правом `read:packages`. Если сделаете пакет публичным, pull можно будет упростить.

## Важные замечания

- Локальная цена берется не из TradingView, а напрямую из публичного `MOEX ISS` endpoint.
- Контракт выбирается автоматически как фьючерс с минимальной `LASTTRADEDATE`, которая еще не наступила для текущего московского дня.
- Если нужен конкретный контракт, его можно явно передать в команде, например `/cocoa CCM6`.
- `USDRUBF` и `COCOA` по-прежнему берутся из TradingView через пакет `tradingview-ws`.
- В интервале между открытием и закрытием внешнего рынка бот не считает спред, потому что закрытие зарубежного какао еще не сформировано.
- На выходных внешний рынок считается закрытым, и для `COCOA` используется последнее закрытие предыдущего торгового дня.
- Если заполнен `FOREIGN_MARKET_HOLIDAYS_MSK`, бот также исключает эти даты из торгового календаря внешнего рынка и берет последнее закрытие предыдущего торгового дня.
- В `FOREIGN_MARKET_HOLIDAYS_MSK` нужно указывать только полные нерабочие даты. Ранние закрытия вроде дня после Thanksgiving или `24 декабря 2026` туда добавлять не нужно.
- Расчетный базис сейчас считается по приближенной carry-модели:
- `fair_basis ~= цена закрытия COCOA * ставка * дни до экспирации / база_дней`
- дни считаются от времени закрытия внешнего рынка до даты экспирации локального контракта
- если `FAIR_BASIS_RATE_PCT` пустой, бот автоматически подгружает последнюю опубликованную ключевую ставку с официальной страницы ЦБ РФ
- кеш ставки ЦБ можно отключить через `CBR_KEY_RATE_CACHE_ENABLED=false`
- кеш закрытия `COCOA` до следующего открытия внешнего рынка можно отключить через `TV_WORLD_CLOSE_CACHE_ENABLED=false`
- это не официальный биржевой базис, а рабочая аппроксимация, которую можно калибровать через `FAIR_BASIS_*`
- Пороги рекомендаций настраиваются через `.env`:
- `SIGNAL_NEUTRAL_SPREAD_RUB`, `SIGNAL_NEUTRAL_SPREAD_PCT`
- `SIGNAL_CAUTIOUS_SPREAD_RUB`, `SIGNAL_CAUTIOUS_SPREAD_PCT`
- `SIGNAL_STRONG_SPREAD_RUB`, `SIGNAL_STRONG_SPREAD_PCT`
- В каналах Telegram бот должен быть добавлен как администратор, иначе он не сможет публиковать ответы.
- При желании можно заполнить `BOT_ALLOWED_CHAT_IDS`, чтобы бот отвечал только в указанных чатах или каналах.
